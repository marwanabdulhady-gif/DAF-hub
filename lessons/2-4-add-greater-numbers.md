### Solve & Share

Erica's class collected 4,219 bottles for the recycling halalaher. Ana's class collected 3,742 bottles. Leon's class collected 4,436 bottles. How many bottles did the three classes collect? Solve this problem any way you choose.

Just like you did with smaller numbers, you can break up greater numbers by place value to help you add.

**Look Back!** Generalize: Which properties allow you to change the order and grouping of numbers to add? How did you use these properties?

### Essential Question

How do you add greater numbers?

### Visual Learning Bridge

Plans for remodeling a sports stadium include adding an additional 19,255 seats. How many seats will be in the remodeled stadium?

Seats in the original stadium: 20,000 + 4,595 = 24,595

You can use a **variable** to represent the unknown value. The variable *s* represents the total number of seats in the remodeled stadium.

You can use an **algorithm**, which is a set of steps used to solve a math problem.

You can add two or more numbers when you line up the numbers by place value. Add one place at a time.

**Step 1:** Add the ones, then the tens, then the hundreds. Regroup if necessary.

**Step 2:** Add the thousands and the ten thousands. Regroup if necessary.

```
   24,595
+  19,255
   43,850
```

*s* = 43,850  
The remodeled stadium will have **43,850 seats**.

**Step 3:** Use an estimate to check if your answer is reasonable.

25,000 + 19,000 = 44,000  
43,850 is close to the estimate of 44,000, so the answer is reasonable.

**Convince Me!** Construct Arguments: When using the standard algorithm to add 24,595 + 19,255, how do you regroup 1 ten + 9 tens + 5 tens?

### Another Example

Find 30,283 + 63,423 + 6,538. Explain how to check that your answer is reasonable.

**Estimate:** 30,000 + 63,000 + 7,000 = 100,000

```
   30,283
   63,423
+   6,538
  100,244
```

The sum is reasonable because it is close to the estimate of 100,000.
