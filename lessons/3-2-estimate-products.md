### Solve & Share

Saud earns SAR 48 a week tutoring younger brothers at the masjid homework club. He saves all of his earnings for 6 weeks. Estimate about how much Saud saves. Solve this problem using any strategy you choose.

How can reasoning about place value make it easier to estimate products?

**Look Back!** Is your estimate more or less than the amount Saud actually earned? Explain.

### Essential Question

How can you estimate products?

### Visual Learning Bridge

Ustadh Hatem's class sold calendars and note pads for 3 weeks as a class fundraiser. About how much did Ustadh Hatem's class make selling calendars? selling note pads?

| Item | Week 1 | Week 2 | Week 3 | Price |
|------|--------|--------|--------|-------|
| Calendar | 28 | 73 | 63 | SAR 4 |
| Note Pads | 272 | 475 | 232 | SAR 3 |

**Use compatible numbers** to estimate how many calendars *c* were sold.  
28 + 73 + 63 = *c* → 164 = *c*  
164 is close to 150. 4 × 150 = 600  
Ustadh Hatem's class made about **SAR 600** selling calendars.

**Use rounding** to estimate how many note pads *n* were sold.  
272 + 475 + 232 = *n* → 979 = *n*  
To the nearest thousand, 979 rounds to 1,000.  
3 × 1,000 = 3,000  
Ustadh Hatem's class made about **SAR 3,000** selling note pads.

**Convince Me!** Construct Arguments: Could you solve the problem above by rounding to estimate the total number of calendars and the total number of note pads? Explain.

### Another Example

Ustadha Laila's class made SAR 2,089 selling neon pencil packs. A student calculated that Ustadh Hatem's class and Ustadha Laila's class together made SAR 8,865 selling the school supplies. Is the student's calculation reasonable?

Round Ustadha Laila's total to the nearest thousand: SAR 2,000. Then add the rounded amounts. SAR 2,000 + SAR 600 + SAR 3,000 = SAR 5,600.

The student's calculation is not reasonable because SAR 8,865 is not close to SAR 5,600.

You can estimate to check if an answer is reasonable.

### Problem Solving

School mascot voting graph; infant vs adult sleep; running estimates.
