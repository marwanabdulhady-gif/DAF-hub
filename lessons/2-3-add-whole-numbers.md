**Look Back!** When adding, how do you know when there are enough tens to make one hundred?

### Essential Question

How do you add whole numbers?

### Visual Learning Bridge

The Jeddah Municipality set a statewide recycling goal. To help meet this goal, Dar Ali Fikr Boys School school students collected newspaper. How many pounds of newspaper did they collect in all?

| Month | Pounds |
|-------|--------|
| March | 358 |
| April | 277 |

Add 358 + 277.  
**Estimate:** 350 + 250 = 600

**Add using partial sums.**

```
  358
+ 277
  15    8 ones + 7 ones
 120    5 tens + 7 tens
+500    3 hundreds + 2 hundreds
 635
```

**Add using the standard algorithm.**

**Step 1** Add ones.  
8 ones + 7 ones = 15 ones. Regroup. 15 ones = 1 ten + 5 ones.

**Step 2** Add tens.  
5 tens + 7 tens + 1 ten = 13 tens. Regroup: 13 tens = 1 hundred + 3 tens.

**Step 3** Add hundreds.  
3 hundreds + 2 hundreds + 1 hundred = 6 hundreds.

The students collected **635 pounds** of newspaper.

Connect adding partial sums to adding using the standard algorithm for addition.

**Convince Me!** Use Structure: In the problem above, when you add partial sums you can add the ones first or the hundreds. Can you do the same when you add using the standard algorithm?
