🛠️ ActivityEngine Developer Guide & Architecture

ActivityEngine is a modular, zero-dependency educational activity runtime built to power Wordwall-style mechanics in web applications, LMSs (Moodle, Canvas, Blackboard), and standalone single-file HTML deliverables.

1. Embedding in any HTML Document

Simply include the CSS and JS files, create a target container div, and initialize the engine with a JSON activity object:

<!-- 1. Include Stylesheet & Runtime --> <link rel="stylesheet" href="css/activity-engine.css"> <script src="js/sound-synth.js"></script> <script src="js/particles.js"></script> <script src="js/activity-engine.js"></script> <!-- 2. Mount Point --> <div id="my-activity"></div> <!-- 3. Initialize --> <script> const game = new ActivityEngine('#my-activity', { theme: 'chalkboard', sound: true }); game.load({ type: 'matching', title: 'States of Matter', instruction: 'Match each state to its property.', data: [ { left: 'Solid', right: 'Fixed shape and volume' }, { left: 'Liquid', right: 'Fixed volume, variable shape' }, { left: 'Gas', right: 'Expands to fill container' } ] }); game.on('score', (data) => console.log('Score updated:', data)); game.on('complete', (summary) => console.log('Activity finished:', summary)); </script>

2. Supported Activity Types & Mechanics

Type Key Mechanic Description Data Payload Structure
matching Pair connecting with SVG dynamic bezier lines, tap/drag nodes Array<{ left: string, right: string }>
wordsearch Dynamic letter matrix with multi-angle touch/drag line finder { gridSize: number, words: string[] }
reading Two-pane story reader with Web Speech TTS & interactive quiz { passageTitle, passageText, questions: [] }
sorting Category buckets with drag-and-drop & tap-to-place items { categories: [], items: [] }
cloze Fill-in-the-blank passage with draggable chips & distractors { text: "The {sun} rises in...", distractors: [] }
diagram Hotspot canvas pins and draggable label tags { diagramSvg, labels: [{ id, name, x, y }] }
quiz Timed gameshow quiz with 50/50 lifeline & streak bonus { questions: [{ question, options, answerIndex }] }
wheel Interactive physics spinning wheel with pointer ticking audio { items: string[] }
anagram Tile unjumble letter placement on tactile shelf { clue: string, word: string }
speedtap Whack-a-mole fast reflex target identification { instruction, targets: [], distractors: [] }
crossword Interactive crossword grid with keyboard navigation { grid: string[][], clues: [] }
memory 3D card flip matching pairs { pairs: [{ a, b }] }
